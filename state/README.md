# state/

Generated operational data — gitignored except this file.

- `opportunities.json`, `matches.json`, `packets/`, `briefs/`, `qc-log.md`,
  `outreach/` — pipeline outputs, regenerated by runs.
- `sam_request_ledger.json` — today's SAM.gov request count (the budget guard).
- `suppression.json` — **the opt-out list. Never delete; back it up.** Shape:
  `{"emails": [], "domains": []}`. Every unsubscribe/objection goes here before
  the next outreach batch is drafted.
- `niche_scores.json` — output of `python -m bidscout score-niches`.
